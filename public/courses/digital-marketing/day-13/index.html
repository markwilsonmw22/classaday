Scraping with Python

4 hours

Write, run and adapt Python scrapers: one that collects a full product list with pagination, and a mini SEO crawler for any site's sitemap.

Lesson 35 minExample 25 minTasks 180 min≈ 4.0 h total

1Lesson

No-code tools are great until you need something custom. A few lines of Python can collect thousands of rows exactly the way you want. You don't need to be a programmer: read each line, run it, then ask an AI assistant to help you adapt it.

Setup (15 minutes)

  1. Install Python 3 from python.org (tick "Add Python to PATH" on Windows).
  2. Install VS Code (free) and its Python extension.
  3. In a terminal, install two libraries:
pip install requests beautifulsoup4

requests downloads pages. beautifulsoup4 (BeautifulSoup) reads the HTML and lets you pick out parts with CSS selectors.

Scraper 1: every book on a practice site

books.toscrape.com is a website built for people learning to scrape, so you can practise freely. Save this as books.py and run python books.py:

"""Collect every book on books.toscrape.com (a practice site) into books.csv."""
import csv
import time
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

START = "https://books.toscrape.com/"
HEADERS = {"User-Agent": "MapleAndPixel-learning-bot/1.0 (you@example.com)"}
RATINGS = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5}


def scrape_page(url):
    response = requests.get(url, headers=HEADERS, timeout=15)
    response.raise_for_status()
    soup = BeautifulSoup(response.content, "html.parser")

    books = []
    for card in soup.select("article.product_pod"):
        link = card.select_one("h3 a")
        rating_word = card.select_one("p.star-rating")["class"][1]
        books.append({
            "title": link["title"],
            "price": card.select_one("p.price_color").get_text(strip=True),
            "rating": RATINGS.get(rating_word, 0),
            "in_stock": "In stock" in card.select_one("p.availability").get_text(),
            "url": urljoin(url, link["href"]),
        })

    next_link = soup.select_one("li.next a")
    next_url = urljoin(url, next_link["href"]) if next_link else None
    return books, next_url


def main():
    url, all_books = START, []
    while url:
        books, url = scrape_page(url)
        all_books.extend(books)
        print(f"{len(all_books)} books so far")
        time.sleep(1)  # be polite: at most one request per second

    with open("books.csv", "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=all_books[0].keys())
        writer.writeheader()
        writer.writerows(all_books)
    print(f"Saved {len(all_books)} books to books.csv")


if __name__ == "__main__":
    main()

What each part does:

  • requests.get(...) downloads the page. raise_for_status() stops with an error if the page fails.
  • soup.select("article.product_pod") finds every book card. select_one finds the first match inside a card.
  • urljoin turns relative links like catalogue/page-2.html into full URLs.
  • The while url: loop follows the Next button until there isn't one. That's pagination.
  • time.sleep(1) waits a second between pages.
  • csv.DictWriter saves everything in a file Google Sheets or Excel can open.

Scraper 2: a mini SEO crawler for any site

This one reads a site's sitemap, checks robots.txt, and records the status, title, description, H1 and word count of each page. Use it on your own or a client's site. Save as seo_check.py and run python seo_check.py https://yoursite.com/:

"""Mini SEO checker: read a sitemap and record on-page basics for each URL."""
import csv
import sys
import time
import urllib.robotparser
import warnings
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup, XMLParsedAsHTMLWarning

warnings.filterwarnings("ignore", category=XMLParsedAsHTMLWarning)  # sitemaps are XML; that's fine

SITE = sys.argv[1] if len(sys.argv) > 1 else "https://example.com/"
HEADERS = {"User-Agent": "MapleAndPixel-SEO-check/1.0 (you@example.com)"}
LIMIT = 200  # pages to check at most

robots = urllib.robotparser.RobotFileParser(urljoin(SITE, "/robots.txt"))
robots.read()


def sitemap_urls(sitemap_url):
    page = requests.get(sitemap_url, headers=HEADERS, timeout=15)
    soup = BeautifulSoup(page.content, "html.parser")
    locs = [loc.get_text(strip=True) for loc in soup.find_all("loc")]
    if soup.find("sitemapindex"):  # a sitemap of sitemaps: open each one
        return [url for child in locs for url in sitemap_urls(child)]
    return locs


def check(url):
    if not robots.can_fetch(HEADERS["User-Agent"], url):
        return {"url": url, "status": "blocked by robots.txt"}
    response = requests.get(url, headers=HEADERS, timeout=15)
    soup = BeautifulSoup(response.content, "html.parser")
    title = soup.title.get_text(strip=True) if soup.title else ""
    desc_tag = soup.find("meta", attrs={"name": "description"})
    description = desc_tag.get("content", "").strip() if desc_tag else ""
    h1s = soup.find_all("h1")
    return {
        "url": url,
        "status": response.status_code,
        "final_url": response.url,
        "title": title,
        "title_length": len(title),
        "description": description,
        "description_length": len(description),
        "h1_count": len(h1s),
        "h1": h1s[0].get_text(strip=True) if h1s else "",
        "words": len(soup.get_text(" ", strip=True).split()),
    }


def main():
    urls = sitemap_urls(urljoin(SITE, "/sitemap.xml"))[:LIMIT]
    print(f"Checking {len(urls)} pages...")
    rows = []
    for url in urls:
        rows.append(check(url))
        time.sleep(1)
    fields = list(max(rows, key=len).keys())
    with open("seo_check.csv", "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        writer.writerows(rows)
    print("Saved seo_check.csv")


if __name__ == "__main__":
    main()

Open the CSV and sort by title_length, h1_count and status to spot problems in seconds.

Pages built with JavaScript

Some sites load content with JavaScript after the page arrives, so requests sees an empty shell. Use Playwright, which drives a real browser:

pip install playwright
playwright install chromium

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://quotes.toscrape.com/js/")
    page.wait_for_selector(".quote")
    quotes = page.locator(".quote .text").all_inner_texts()
    print(quotes[:3])
    browser.close()

Using AI to write scrapers

AI assistants are excellent at this. Give them:

Here's the HTML of one item from the page (pasted below). Write a Python scraper with requests and BeautifulSoup that collects name, price and link for every item, follows the "Next" link, waits 1 second between pages, and saves to CSV. Explain each line simply.

Then run it, read the error if there is one, and paste the error back. That loop is how professionals work too.

When scrapers break

Websites change their HTML. When a scraper returns empty results, open the page, Inspect the element again and update the selector. Keep selectors simple and based on stable names (IDs, meaningful classes), not long chains of div > div > div.

2Worked example

Riya's first real Python job.

A café-supply client asks which of their 180 product pages have missing descriptions or duplicate titles. Riya runs seo_check.py against the client's sitemap. Three minutes later (with polite one-second delays):

  • 31 pages have no meta description
  • 12 pages share the title "Shop | BeanCo"
  • 4 URLs return 404 but are still listed in the sitemap
  • 9 pages have no H1

She sorts the CSV, pastes the top issues into the client's monthly report and bills the fixes as a small project. The script took her an hour to adapt with an AI assistant. It now runs for every new client in her onboarding.
